# Metodo IMPATTO Astro

Versione statica/editoriale di Metodo IMPATTO basata su Astro, pensata per Cloudflare Pages.

## Comandi

```bash
npm install
npm run dev
npm run build
```

## Deploy Cloudflare Pages

- Framework preset: Astro
- Build command: `npm run build`
- Output directory: `dist`

## Newsletter

Il componente newsletter e pronto per Brevo. In questa prima versione mostra un fallback editoriale coerente con la rubrica "Il Prompt della Settimana".
